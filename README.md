# Velvet Bakes

A responsive, static storefront for Velvet Bakes. The owner menu studio lets you add and remove items in the browser.

## Publish on GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

GitHub Pages serves static files only. Menu edits currently live in the browser's local storage, so they are visible only on that device and browser. For shared updates across devices, connect a hosted database and add owner authentication before using the editor publicly.

## Store details

Address and contact details are based on the supplied listing. Menu names and displayed prices are sample values; update them in `script.js` or through the owner studio. The phone number and map links point to the listing details supplied.
